# 股票工作台

跨平台个人股票工作台：盯盘自选、指标图表、价格提醒、模拟持仓、日报简报、复盘笔记。本地优先（SQLite / sql.js），中文界面，无需 API Key。

**当前版本：v0.5.0** — 简单 UX，更深功能。

## 30 秒上手

```bash
cd stock-workstation
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`，然后：

1. **盯盘**顶栏输入 `600519` 或 `AAPL`，回车 → 加入自选  
2. 点选股票看 K 线 → 点 **一键模拟买入**（A 股默认 1 手）  
3. 用提醒模板「现价 +3% / −3% / 涨跌≥5%」一键设提醒  
4. 成交后可跳转 **复盘**，自动生成草稿  

按 `?` 查看键盘快捷键（`1`–`5` 切页，`N` 聚焦添加，`R` 刷新行情）。


## 在线演示（GitHub Pages）

部署后访问（把 `USER` / `REPO` 换成你的账号与仓库名）：

**https://USER.github.io/REPO/**

### 启用 Pages（Actions 源）

1. 仓库 **Settings → Pages**
2. **Build and deployment → Source** 选 **GitHub Actions**
3. 推送到 `main` 后，工作流 `.github/workflows/pages.yml` 会自动 `npm ci` → `npm run build` → 上传 `dist/` 并部署
4. 也可在 **Actions** 里手动跑 **Deploy GitHub Pages**

本地构建产物在 `dist/`（`base` 默认为 `./`，适配项目页路径）。若需要绝对前缀：

```bash
VITE_BASE=/REPO/ npm run build
```

## 功能一览（v0.5）

| 能力 | 说明 |
|------|------|
| 盯盘 | 自选 + 分组标签 + 日/周/月/分钟 K + MA/VOL/MACD |
| 走势对比 | 勾选 2–3 只，叠加归一化（起点=100）相对表现 |
| 一键买入 | 图表旁市价模拟买入，确认后可进复盘草稿 |
| 提醒 | 模板一键 + 稍后/免打扰；监听中 / 已触发分栏 |
| 模拟 | 市价/限价、手数、止损备注、净值曲线、CSV |
| CSV 重算 | 导入可选按成交回放现金；一键修复现金漂移 |
| 日报 | 持仓速览置顶；芯片跳转盯盘或模拟 |
| 复盘 | 从最近成交自动/一键草稿 |
| 设置 | 行情健康、源优先级、免打扰时段、账户重置 |

高级选项（术语词典、自定义提醒、CSV、账户重置）默认收在 **「高级」** 折叠里。

## 行情源

| 源 | 说明 |
|----|------|
| 东方财富 | A 股友好，日/周/月/分钟 |
| 新浪财经 | A 股实时串 |
| Yahoo | 美股/港股较好 |
| 缓存 | 上次成功价，TTL ≈30 分钟 |
| 模拟 | 随机游走，保证 UI 不空白 |

默认回退：**东财 → 新浪 → Yahoo → 缓存 → 模拟**。

| 运行环境 | 行情如何到达浏览器 |
|----------|-------------------|
| `npm run dev` | Vite 开发代理 `/api/yahoo`、`/api/eastmoney`、`/api/sina` 等（绕过 CORS） |
| Electron 桌面包 | 主进程/渲染直连 HTTPS，无浏览器 CORS 限制 |
| **GitHub Pages 静态站** | **没有** Vite 代理。客户端先直连公开源，再尝试公共 CORS 中继（`corsproxy.io`，尽力而为、可能限流）；仍失败则用 **SQLite 缓存 → 本地模拟**，保证 UI 可用 |

> Pages 上的「真实行情」依赖源站 CORS 或公共中继是否可用；断网或中继不可用时会自动落到缓存/模拟，这是预期行为，不是构建失败。

## 进阶

### CSV

成交表头：

```text
symbol,name,side,qty,price,fee,ts
600519.SH,贵州茅台,buy,100,1680,5.04,2026-09-28T08:00:00.000Z
```

导入默认勾选 **「导入后按成交日志重算现金」**，从起始资金回放全部买卖与费用，修复仅追加成交导致的现金漂移。也可在高级区点 **「从成交重算现金」**。

### 模拟规则

- A 股数量按 **100 股（1 手）**；美/港股按 1 股步进  
- 买入/卖出前确认；成交写净值快照  
- 止损/止盈仅备注，**不自动下单**  
- 账户以 **CNY** 为本位，外币示意折算（非实时 FX）

### 提醒

- 设置页可配 **免打扰时段**（默认 23:00–07:00，起止相同则关闭）  
- 触发后可 **稍后 1h** 或 **重新监听**；监听中 / 已触发分栏查看

## 限制与声明

- 公开行情常延迟；分钟线依赖源是否返回数据  
- GitHub Pages 为纯静态托管：无服务端代理；真源可能因 CORS/中继不可用而回退到缓存或模拟  
- 多币种折算为示意汇率，**不是**实时外汇  
- 价格提醒仅应用内 Toast，不做系统推送；免打扰仅抑制 Toast  
- 现金重算以初始 ¥1,000,000 与成交费用为准，不含手动改账  
- 对比图按日线对齐归一化，不处理分红/拆股复权差异  
- 本工具仅供个人学习，**不构成投资建议**
