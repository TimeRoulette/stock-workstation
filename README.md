# 股票工作台

跨平台个人股票工作台：盯盘自选、指标图表、价格提醒、模拟持仓、日报简报、复盘笔记。本地优先（SQLite / sql.js），中文界面，无需 API Key。

**当前版本：v0.11.0** — 实盘分析 · 工程拆分 · 规则单测扩展 · Electron 托盘/开机可选 · 无障碍 · 可选本机 LLM · Android 脚手架。

## 30 秒上手

```bash
cd stock-workstation
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`，然后：

1. **盯盘**顶栏输入 `600519` 或 `AAPL`，回车 → 加入自选  
2. 点选股票看 K 线 → 点 **一键模拟买入**（A 股默认 1 手）  
3. 用提醒模板「现价 +3% / −3% / 涨跌≥5%」一键设提醒  
4. 成交后可跳转 **复盘**，自动生成草稿  

按 `?` 查看键盘快捷键（`1`–`8` 切页，`N` 聚焦添加，`R` 刷新行情）。

## 行情源

| 源 | 说明 |
|----|------|
| 东方财富 | A 股友好，日/周/月/分钟 |
| 新浪财经 | A 股实时串 |
| 同花顺 | A 股 web realhead（CORS *，无密钥） |
| Yahoo | 美股/港股较好 |
| 缓存 | 上次成功价；新鲜 TTL ≈30 分钟，失败时可放宽至 24 小时 |
| 模拟 | 随机游走；仅当完全无缓存时使用 |

默认回退：**东财 → 新浪 → 同花顺 → Yahoo → 缓存（含放宽 TTL）→ 模拟**。  

**日报源（v0.8）**：人民日报财经 RSS、央视财经、华尔街见闻全球快讯、BBC Business RSS、美联储新闻稿 RSS、东财板块榜；session 缓存约 8 分钟；失败标示意，不伪造实时。

未接入（Pages）：同花顺期货通（需密钥/客户端）、通达信（TCP 本地桥）、指南针/华宝智投（无公开 API）、财联社（需签名）、开盘啦（App 私有协议）。

| 运行环境 | 行情如何到达浏览器 |
|----------|-------------------|
| `npm run dev` | Vite 开发代理 `/api/yahoo`、`/api/eastmoney`、`/api/sina`、`/api/ths` 等（绕过 CORS） |
| Electron 桌面包 | 主进程/渲染直连 HTTPS，无浏览器 CORS 限制 |
| **GitHub Pages 静态站** | **没有** Vite 代理。同花顺/东财等若源站允许 CORS 则直连；否则公共中继尽力而为；仍失败则 **SQLite 缓存 → 本地模拟** |

> Pages 上的「真实行情」依赖源站 CORS 或公共中继是否可用；断网或中继不可用时会自动落到缓存/模拟，这是预期行为，不是构建失败。

## 进阶

### CSV

成交表头：

```text
symbol,name,side,qty,price,fee,ts
600519.SH,贵州茅台,buy,100,1680,5.04,2026-09-28T08:00:00.000Z
```

导入默认勾选 **「导入后按成交日志重算现金」**，从起始资金回放全部买卖与费用，修复仅追加成交导致的现金漂移。也可在高级区点 **「从成交重算现金」**。

### 模拟规则

- A 股数量按 **100 股（1 手）**；美/港股按 1 股步进  
- **市价**立即成交；**限价**进入待成交队列，行情刷新时按演示规则撮合（买：最新价≤限价；卖：最新价≥限价；成交价用限价），可取消  
- 止损/止盈：默认可仅备注；可选「触及提醒」（Toast/系统通知，尊重免打扰）；可选「演示自动平仓」（**非券商撮合**）  
- 简易绩效：已平仓 FIFO 胜率、净值最大回撤、相对沪深300等基准示意（数据不可用则标明）  
- 账户以 **CNY** 为本位，外币示意折算（非实时 FX）

### 窗口 / PWA

- 提供 Web App Manifest + Service Worker，可「安装到应用」以 standalone 打开，减少多标签  
- 命名窗口 `stock-workstation`；重复实例用 BroadcastChannel / localStorage 心跳检测并提示聚焦  
- **限制**：从任意外链点开主站 URL 时，浏览器无法 100% 强制合并标签（安全策略）；收藏夹 / PWA 是务实方案  
- 站内所有 http(s) 外链走 `openExternalLink`：同 URL 复用已开窗口

### 提醒

- 设置页可配 **免打扰时段**（默认 23:00–07:00，起止相同则关闭）  
- 触发后可 **稍后 1h** 或 **重新监听**；监听中 / 已触发分栏查看

## 限制与声明

- 公开行情常延迟；分钟线依赖源是否返回数据  
- GitHub Pages 为纯静态托管：无服务端代理；真源可能因 CORS/中继不可用而回退到缓存或模拟  
- 多币种折算为示意汇率，**不是**实时外汇  
- 价格提醒：应用内 Toast；可选系统通知（需授权）；免打扰同时抑制 Toast 与系统通知  
- 现金重算以初始 ¥1,000,000 与成交费用为准，不含手动改账  
- 对比图按日线对齐归一化，不处理分红/拆股复权差异  
- 选股个股榜默认最多前 200（4×50）；技术扫描推荐前200/自选；全市场慢且 Pages 受限；板块成分股单次约 80 只；龙头/中军为启发式标注
- 限价撮合与止损自动平仓均为**演示规则**，非真实券商撮合
- 绩效与基准对比仅供研究，非券商对账单
- PWA/命名窗口无法保证任意外链 100% 合并到同一浏览器标签
- 实盘数据为用户手动导入，仅本地存储；非券商对接，不做未授权爬取登录
- LLM Key 仅 Electron 本机存储，不会进入 GitHub Pages 构建产物
- Android debug APK 仅供自测，非商店发行版
- 本工具仅供个人学习，**不构成投资建议**
